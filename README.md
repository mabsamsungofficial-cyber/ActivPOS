# ActivPOS

This project is a production-ready React application built from the provided source in `ActivPOS.md`.

## Stack

- React 18
- Vite
- Tailwind CSS
- XLSX for spreadsheet imports
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
